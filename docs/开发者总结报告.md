## 三、精灵图体系（核心资产）

### 3.1 核心类职责

| 类 | 职责 | 关键函数 |
|----|------|---------|
| `SpriteDef` | 硬编码精灵坐标 + 帧尺寸 | `Icons.frame(5)` 返回 `SpriteFrame(x,y,w,h)` |
| `SpriteLoader` | 缓存 + 加载 + 快捷工具 | `setIcon(view, 5)` `setButton(view, res, frame)` `background48(2)` `processBar(index)` |
| `PixelGraphics` | 底层 Canvas 绘制 | `drawSprite()` `drawNinePatch()` `crop(scale)` `ninePatchDrawable()` |

## 五、核心架构（v2.0）

### 5.1 AddonTool 功能面板（7 工具）

| 面板 | ID | 功能 |
|:----:|:--:|------|
| 工具 1 | `toolPanel1` | 新建任务 |
| 工具 2 | `toolPanel2` | 新建文档（空白/导入） |
| 工具 3 | `toolPanel3` | 添加图片 |
| 工具 4 | `toolPanel4` | 随机一下（HINT 日志） |
| 工具 5 | `toolPanel5` | 数据统计（绿墙日历） |
| 工具 6 | `toolPanel6` | 回收站（软删除日志查看） |
| 工具 7 | `toolPanel7` | 属性账单 |

### 5.2 LogEditorActivity 三模式

| 模式 | 内容区 | 工具栏 | 属性变更 |
|:----:|--------|--------|:--------:|
| `MODE_DEFAULT` | NoteContentEditText（富文本） | 完整格式工具 | ✅ |
| `MODE_PICTURE` | NoteContentEditText + 缩略图 | 撤销/重做 + 标签/短语/属性 | ✅ |
| `MODE_DOCUMENT` | EditText + RecyclerView 预览 | 编辑 toggle + 标签/短语/属性 | ❌ |

### 5.3 文件存储策略

```
files/
├── images/
│   ├── {YYYYMMDD}_{hhmmss}_{原始文件名}.jpg         ← 原图（≤8MB）
│   ├── thumb_{YYYYMMDD}_{hhmmss}_{原始文件名}.jpg   ← 缩略图（720px 宽）
│   └── avatar.jpg                                    ← 用户头像
└── documents/
    └── {YYYYMMDD}_{hhmmss}_{原始文件名}.md           ← 纯文本（≤512KB）
```

### 5.4 通知系统

```
PieceOfLifeApp.onCreate() → 通知渠道 (CHANNEL_ID_QUEST_REMINDER)
QuestReminderReceiver.onReceive()
  → 统计 today + thisWeek 到期任务
  → 构建通知（smallicon + 内容）
  → NotificationManagerCompat.notify(NOTIFICATION_ID_QUEST)
```

### 5.5 头像系统

```
UserSetting: iconAvatarPreview(btn16) + tvAvatarStatus + btnAvatarPicker
  → 系统图片选择器 → cropSquareTopLeft → avatar.jpg → HINT 日志
MainActivity: FrameLayout { ivAvatar + ivAvatarBorder(background_input2) }
  → initAvatar() 在 refresh 时自动重新加载
```

### 5.6 备份系统

```
ZIP 包: manifest.json + pieces_of_life.db + images/* + documents/*
进度: ProgressDialog（ProcessBar 精灵 + 可取消）
缺失文件: 导入后写 HINT 日志告知
```

## 六、开发习惯与约定

### 6.1 代码风格

- 所有新文件使用 Kotlin
- `object` 单例用于工具类
- 纯函数优先（如 `PixelGraphics`）
- 不自行执行 `gradlew` / `git commit`

### 6.2 精灵图

- 通过 `SpriteDef.frame(index)` 获取坐标
- `setButton()` 后不要再调用 `setOnTouchListener`
- 标准 scale=5，紧凑视图 scale=4

### 6.3 数据层

- Room 开发期使用 `fallbackToDestructiveMigration()`
- 所有查询自动过滤 `is_deleted=0`
- 备份文件为 ZIP 格式（manifest.json + .db + images/ + documents/）
